# New Tenant Onboarding

1. Create the tenant row and a unique lowercase slug.
2. Add development, root, and `www` domain rows; verify exactly one primary production domain.
3. Invite the tenant administrator and test their membership before adding editors.
4. Configure legal name, verified phone/email/address, hours, service area, insurance/license facts, review profiles, and social profiles.
5. Choose controlled brand settings: logo, favicon, colors, fonts, radius, header, footer, hero, gallery, and button style.
6. Create six core pages, review all 11 services, and add only services the company genuinely offers.
7. Add up to 20 location drafts using first-party local notes. Keep pages noindex until local quality passes.
8. Upload permission-cleared project photos with descriptive filenames, dimensions, captions, stage labels, and alt decisions.
9. Add projects and link each to the correct services and location.
10. Add only verified testimonials with source/permission records.
11. Create author profiles and three useful reviewed posts grounded in painter observations.
12. Configure contact recipients, sender domain, spam controls, analytics IDs, and verification tokens.
13. Run the SEO audit; resolve every critical issue and assess warnings.
14. Add and verify domains in Vercel, test redirects/HTTPS, and submit the tenant sitemap.
15. Complete the machine-readable and human launch checklists before production-ready status.

Adding a painting company never requires a new repository, copied route, or duplicate component set. New visual variety must come from the controlled branding/theme fields and tenant content.
