# SEO Launch Checklist

A tenant cannot be marked production-ready until every required item passes with evidence.

- [ ] Primary domain ownership and HTTPS are verified.
- [ ] Root/`www` preference redirects once to the primary HTTPS domain.
- [ ] Every canonical and sitemap URL uses the primary domain; no localhost or preview URL appears.
- [ ] Production robots allows public pages and references the tenant sitemap.
- [ ] Preview, dashboard, auth, private API, and draft routes are noindex.
- [ ] Sitemap contains only this tenant's published, indexable, canonical pages.
- [ ] Six core pages, approved services, and quality-approved locations are indexable.
- [ ] Every published page has unique title, description, H1, useful body content, canonical, and internal links.
- [ ] No broken links, orphan pages, redirect chains, loops, duplicate slugs, or severe content duplication remain.
- [ ] Structured data validates and matches visible, verified tenant information.
- [ ] Location pages contain meaningful first-party local information; service pages contain real service expertise.
- [ ] Images are permission-cleared, optimized, dimensioned, descriptively named, and have an alt decision.
- [ ] Mobile layouts, keyboard navigation, forms, and comparison controls pass testing.
- [ ] Lighthouse budgets and real-browser template checks pass.
- [ ] Contact storage/delivery, spam protection, rate limiting, and recipients work for this tenant only.
- [ ] Analytics is tenant-specific and not duplicated.
- [ ] Search Console/Bing verification and sitemap-submission instructions are complete.
- [ ] No demonstration contact details, projects, testimonials, credentials, biographies, or unverified claims remain.
- [ ] Cross-tenant database, Storage, sitemap, metadata, and dashboard tests pass with real credentials.
