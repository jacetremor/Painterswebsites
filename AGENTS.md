# Painter Websites Agent Guidance

For public-site design or frontend work:

1. Read `design-system/nova-suite-painter-websites/MASTER.md`.
2. Use the installed `.codex/skills/ui-ux-pro-max` search tool for relevant
   design, UX, accessibility, and Next.js guidance.
3. Use `docs/DESIGN_PROMPT.md` as the quality brief.
4. Inspect both `summit.localhost:3000` and `heritage.localhost:3000`.
5. Verify desktop and mobile screenshots before declaring the work complete.

Preserve tenant isolation, SEO behavior, authentication, and verified content.
Do not add invented reviews, credentials, claims, locations, or project results.
